<h1 align="center">RepRush</h1>

<p align="center">
  <strong>RepRush</strong> is a complete gym operating system for Android. It serves as a unified platform for gym owners to manage their business (member registration, billing, attendance) and for members to train with AI-generated personalized workout plans, track progress with advanced analytics, and compete on gym-wide leaderboards.
</p>

---

## ðŸŽ¯ Product Vision

RepRush aims to be a complete replacement for the combination of tools a small gym currently uses: a spreadsheet for member tracking, a notebook for attendance, a calculator for billing, and a trainer for programming. All of these collapse into one app that both the gym owner and every member carry in their pocket.

For the gym owner, RepRush eliminates administrative overhead. For the member, it eliminates the need for a personal trainer. For the gym as a business, the gamification layer drives member retention which directly translates to sustained revenue.

## âœ¨ Key Features

### Admin Features (39 Total)

**Member Management:**
- View pending registration requests with applicant details
- Approve or reject registrations with package assignment
- Manual registration for walk-in members
- Full member directory with search by name/email, filter by status
- Suspend, reactivate, or permanently remove member accounts
- View comprehensive member profiles with payment and attendance history

**Membership & Billing:**
- Create, edit, and deactivate membership packages (name, price, duration)
- Record payments (cash, bank transfer, mobile banking)
- Auto-generate and deliver digital receipts via in-app notification
- Send receipts to member email automatically
- View complete payment log with filters by date range and member
- Void incorrectly recorded payments with reason notes

**Business Operations:**
- Mark daily gym attendance for members
- View real-time attendance list and aggregate stats
- Send gym-wide announcements (appear as notifications and banners)
- Automatic expiry reminders to members (7 days, 3 days, 0 days before)
- Configurable grace period for auto-suspension of expired members
- Manual reminder notifications to specific members

**Dashboard & Insights:**
- Live dashboard with 6 key metrics: active members, pending registrations, memberships expiring in 7 days, check-ins today, monthly revenue, yearly revenue
- Drill-down navigation from each metric to detailed views
- Attendance insights: average visits per member per week, busiest days, inactive members (14+ days no visit)

### Member Features (56 Total)

**Workout Planning & AI:**
- 8-step questionnaire for AI plan generation (goal, days/week, split type, session duration, equipment, fitness level, plan duration, injury restrictions)
- Google Gemini 1.5 Flash API integration for personalized workout generation
- Multiple saved plans with easy switching between active plans
- AI Trainer chatbot for on-demand fitness advice (bonus feature)
- Browse and search professional exercise library from Wger API (thousands of exercises with images)
- Add custom exercises not in the Wger database

**Workout Logging:**
- Log workouts from active plan (exercises pre-loaded with images) or create blank sessions
- Log sets with weight, reps, and completion
- Warmup set flagging (excluded from points and PR calculations)
- Auto-save session state every 30 seconds (crash recovery)
- Rest timer with foreground service (works with screen off)
- Session notes and free-form comments

**Personal Records & Strength:**
- Automatic PR detection on every session per exercise per rep count
- PR history per exercise with date and estimated 1RM (Epley formula)
- Strength Score: sum of estimated 1RM across 5 key compound lifts
- 12-week total volume trend tracking

**Gamification:**
- Points system: 50 pts attendance + 10 per exercise + 2 per set + 100 per PR (500 daily cap)
- Streak tracking (7-day = 200 pts, 30-day = 1000 pts bonus)
- 11 achievement badges (First Rep, On a Roll, Unstoppable, Century Club, PR Machine, Plan Master, heavy lift badges, Comeback Kid, Full House)
- Gym-wide monthly leaderboard (opt-in/opt-out)
- Profile with stats showcase and achievement gallery

**Progress & Analytics:**
- **Overview Tab**: Workout volume heatmap, history list, weekly volume per muscle group bar chart
- **Body Tab**: Daily weight log, line chart with 7-day rolling average, stat chips (starting, current, monthly change, all-time change, lowest)
- **Strength Tab**: Strength Score with history chart, 5 per-lift trend cards, 12-week volume bar chart
- **Heatmap**: GitHub-style calendar showing 6 months of workout history with color intensity based on total lifting volume
- **Session Replay**: View full details of any past session including all exercises, sets, warmup flags, PR flags

**Membership & Notifications:**
- Always-visible membership card with package, expiry date, and countdown
- Color-coded expiry urgency (green 10+ days, amber 3-10 days, red under 3 days or expired)
- Payment history with viewable receipts
- In-app notification inbox for approvals, receipts, reminders, announcements
- Real-time sync across devices

## ðŸ›  Tech Stack

RepRush is built with a modern Android stack optimized for performance, offline reliability, and seamless cloud sync:

**Core Framework:**
- **Language**: Kotlin 1.9+
- **Min SDK**: Android 8.0 (API 26) | **Target SDK**: Latest stable

- **Cloud**: Firebase Firestore with offline persistence enabled
- **Preferences**: DataStore for lightweight settings
- **Caching**: Glide for image loading and caching

**UI & Design:**
- **Theme System**: Material 3 DayNight with dynamic color (Android 12+)
- **View Binding**: ViewBinding for compile-safe view access
- **Navigation**: Jetpack Navigation Component with safe args
- **Charts**: MPAndroidChart for LineChart, BarChart, and sparklines
- **Calendar**: Kizitonwose HeatMapCalendar v2.5.0 for workout volume heatmap
- **Animations**: MaterialSharedAxis, MaterialFadeThrough, ObjectAnimator, DynamicAnimation

**Concurrency & Async:**
- **Coroutines**: Kotlin Coroutines with Flow
- **Background Tasks**: WorkManager for scheduled operations
- **Services**: Foreground Service for rest timer (screen-off operation)

**Authentication & Sync:**
- **Google Sign-In**: Firebase Authentication
- **Cloud Storage**: Firebase Firestore with Realtime Sync
- **Security Rules**: Firestore security rules enforcement

**External APIs:**
- **AI Workouts**: Google Gemini 1.5 Flash API for plan generation and chatbot
- **Exercise Database**: Wger REST API (public, no auth required)
- **Email**: JavaMail API for receipt delivery

**Testing & Debugging:**
- **Logging**: Firebase Crashlytics for crash reporting
- **Testing**: JUnit, Mockito (foundation in place)

1. **Room (Local SQLite)** â€” Optimized for speed and offline functionality
   - All member fitness data: workout sessions, exercises, plans, PRs, heatmap data
   - User profiles, packages, payments, attendance (cached from Firestore)
   - Chat history and achievement records
   - Queries complete in <300ms
   - No network dependency for member features

2. **Firebase Firestore (Cloud)** â€” Single source of truth for shared data
   - Admin operations: member registration, approvals, suspensions
   - Shared state: membership status, expiry dates, payment history
   - Cross-device sync: points, leaderboard rankings, streaks
   - Real-time listeners for business metrics
   - Offline persistence enabled for reads
